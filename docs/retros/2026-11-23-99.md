## Trap hit

- `cstack/test/test-run.test.ts` starts a child process that imports `cstack/src/test-run.ts` as TypeScript source. There, an import that ends in `.js` finds no file, so `test-run.ts` can hold only type imports at the top. Unit 3 had to load the reader with a dynamic `import()` (commit 75f2b00), and the plan's rule that `runTests()` never throws for a report has an exception for that child.
