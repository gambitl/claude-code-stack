## Protect

Phase 4 tested the real `gh` client, read-only, before planning. `gh pr view` exits with 1 when the branch has no pull request, and `gh pr checks` exits with 1 when there is no check yet. These two answers (History, questions 3 and 6) became decisions that the code of units 6 and 8 follows.

The advisor's block before the plan found that a failed test run after the update would let the next run push untested code (History, question 2). The marker file `publish-tests.json` that closes this gap was planned and tested in unit 7.

Unit 8 had to raise `testTimeout` to 30 seconds. Also, `sed -i` needs `-i ''` on macOS: one chain of commands stopped there and a commit was amended, as the "Executor notes" say.
