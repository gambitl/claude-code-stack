## Trap hit

- `listUnitCommits()` in `cstack/src/plan/commits.ts` runs git with the environment of the process, not with the `deps.env` of a command. So a test that breaks git through `deps.env` never reaches it, and a test of its failure must stub the process environment (plan file, `## Decisions`, and "Review log", independent review, item 2). `CLAUDE.md` does not mention it. It cost nothing here, because the question round found it.
