## Trap hit

- A Claude Code session file holds each tool call twice, once on an `assistant` line and once on an `api-request-blob` line with no `timestamp`. Any reader of tool calls must keep only the `assistant` lines and count each call once by its id. The question round caught it, so it cost nothing here, but `CLAUDE.md` does not mention it.
